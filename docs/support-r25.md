# 支持范围与明确限制

- 当前构建为.NET Framework 4.x、Windows x86自有程序，使用本机Windows API。本机已实际使用的Windows环境及401999、317495、395741的既有CWP证据保留；不推及所有壁纸。
- CWP-v2和已支持的v3目录/项目族继续使用原结构规则。新增视频范围是已知lxwp动态缓存wpType=1、MD5命名带lxwp_前缀、固定异或传输、非碎片MP4、AVC视频与可选AAC轨道。不是通用MP4播放器，未知格式、外部数据引用和受保护轨道拒绝。

- 软件数据位置保存库/设置/日志；联想缓存只是导入来源；名称缓存可选且失败不覆盖可靠名称；播放组件目录独立核验，不作为软件数据目录。
- 导入复制到当前数据位置，消耗该盘空间。直接添加已有CWP仍按原登记机制，不宣称所有添加都会复制。运行材料另按512MiB总输入/128MiB且最多两份失败保留策略管理，不保证整个数据目录永不增长。
