# R33 首页、设置与重命名

首页保留标题、固定“设置”、壁纸数量和卡片、选中详情、预览/桌面/停止/隐藏等日常操作及实际播放状态。组件或来源不可用时显示简短提示，直接进入对应设置。采用Material Design 3方向的浅色表面、蓝色重点、圆角胶囊按钮、字阶和留白，保留蓝色折框图标及Windows Forms技术。

## 设置分组

- 来源与存储包含原来源状态、更改入口、个人持久库，以及可选名称缓存说明。现有名称缓存使用固定的当前用户已知位置，没有新增位置选择机制。
- 播放组件复用原发现、完整身份核验、采用、手动选择、30秒预算和取消。打开设置不采用组件，不启动播放。
- 声音与登录包含原声音设置和“登录恢复设置”。原登录恢复默认值及明确操作规则保持，打开本页不写系统配置。
- 详情与诊断分别显示当前选中条目、实际运行条目与任务。查看所选详情、当前会话日志及提交诊断均保留。历史请求和日志保持当时名称。

设置关闭后隐藏并保留当前分组，重新进入复用同一套控件。后台结果写回原处理器，设置可关闭后继续检查，也可以返回取消。主程序退出时释放设置和动效资源。

## 重命名

卡片右键“重命名”和选中操作区“重命名”复用WallpaperNames.Rename。编辑预填当前名称，取消不提交，失败保留输入与旧登记。

名称去除首尾空白，拒绝空值、换行和控制字符，最多80个UTF-16字符单位。允许中文、常见标点及同名，资源ID继续区分条目。80字上限兼顾卡片、省略显示与现有序列化预算。

新增可选CustomName及NameBeforeCustom字段，旧的仅Name登记读取不猜测来源。明确改名时保留第一次改名前名称，原NameSource对象保持。CustomName优先于后续官方名称补充及重复登记。Name继续保存兼容显示值，独立进程读回；保存异常回滚三个名称字段。

当前播放名称按稳定条目ID在个人库中读取，更新首页、设置及托盘展示，不修改原运行请求或重启任务。播放确认、资源路径、哈希与封面关系保持。

## 偏好交互

只读参考组件库revision102的17项明确选用。沿用按压150ms/96%、波纹480ms/240%、等待800ms、悬停240ms/4逻辑像素及选中描边。补入声音/登录的380ms三段弹性开关，设置280ms胶囊分组与240ms导航下划线，240ms自有弹层缩放、3500ms停留的轻滑成功提示、240ms浮动输入标签及就地校验、任务条件驱动的骨架占位、候选名称/ID搜索定位、340ms核验说明折叠和240ms资源摘要展开。

系统文件选择器和明确危险确认框保持系统行为。候选搜索只定位，不自动导入。成功提示仅在真实保存完成后出现，错误保留在行内或诊断。减少动效时保留功能、焦点、文本和状态。拖拽吸附仅在重排业务存在时适用，本轮没有新增排序业务。
