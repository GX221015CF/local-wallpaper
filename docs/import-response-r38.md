# R38导入响应修订

本版保留Material视觉、真实进度、名称补全、搜索和明确导入流程。

## 本次变化

- 候选结果转换、图片读取和解码在后台执行。文字按每批12项提交，图片逐步填充。
- 每个导入窗口的图片缓存最多96项、8MiB像素数据，同时最多2个解码任务。缩略图和详情获得独立位图，关闭后取消工作并释放。
- 同一候选和图片身份保持时复用详情，迟到结果会核对当前选择、代次及窗口生命周期。
- 搜索按当前查询更新可见行，相同结果保持列表、选择和滚动位置。单行状态变化单独更新。
- 相同任务反馈不会重复写提示、布局和进度记录。读取、复制、取消与登记仍按实际任务结果表达。
- 修正列表释放时Resize回调访问已释放列的问题。

## 验证范围

61个自有候选分别使用1600×900和360×203图片，运行真实Application.Run消息循环及正常异步导入入口。TEST_BUILD仅抑制窗口Show，检查线程约束、消息间隔、分段耗时、查询和选择更新。基线和修正结果保存在项目本地证据中。

图片缺失、损坏、变更、缓存容量、查询早于扫描、迟到名称和图片、取消、加载中关闭、重复打开，以及实际小材料复制登记和保存失败均有定向验证。100%、125%、150%采用字体测量与未Show控件布局检查。

真实窗口的滚动绘制、键盘鼠标输入和整体观感仍需一次用户体验。消息循环间隔包含Windows计时与调度，不能直接当作真实帧率。

## 最短体验

打开桌面“本地壁纸”，进入导入窗口。观察文字和图片逐步出现，连续输入中文、ID、清空，选中几项并滚动。关闭再打开，最后正常彻底退出。沿用已有候选即可。

本机隔离场景读取通常为秒级，若超过10秒仍未显示首批候选，或操作持续无响应，停止后续尝试并反馈首个异常。候选读取任务保留45秒硬预算，取消等待原任务退出。
