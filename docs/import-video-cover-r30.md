# 导入前查看视频画面

完整解压后打开 `build\LocalWallpaper.exe`。首次使用选择软件数据位置，首页有已识别来源时点击“导入联想已下载壁纸”。

1. 等待候选自动检查，视频条目的“封面”列会显示“视频画面”，左侧小图和选中后的右侧大图显示该壁纸的一帧。
2. 看到图片并确定是需要的壁纸后，点击“导入所选壁纸”。首页卡片继续使用同一资源的识别图片。
3. 导入后的“预览”和手动“截取封面/替换封面”仍可使用，手动选择的截图优先显示。

自动取帧在检查子任务中使用Windows系统媒体解码，通常取视频开头第一个可识别画面，最多检查45帧、10秒。无需打开播放窗口或准备壁纸播放组件。开头为黑图时会尝试后续画面，仍无可识别画面则说明原因。

当前支持范围沿用已识别的LX本地视频封装及AVC轨道规则，源文件仍须完整哈希、记录MD5、结构及稳定性检查通过。自动图片用于识别，预览确认由用户另外完成。系统缺少媒体解码能力、超时或取帧失败时，保留准确缺图提示，文件检查通过的条目仍可由用户决定是否导入。

封面最大360×240像素，每张不超过1MiB，按完整资源SHA-256保存在当前软件数据位置的 `data\video-covers`。导入将原始视频复制到该数据位置的library，卡片读取同数据位置的图片缓存。取帧期间在该检查任务的cover-temp内临时展开一份已识别视频，完成、失败或取消后清理。既有手动截图、原封面和播放确认分别保留。

本机402242、398417、403178已通过实际Windows离线取帧及发布处理器检查。导入列表的新图片显示仍需一次界面差异确认。旧CWP、R28视频/托盘和R29手动截图已有本机证据继续有效；其他Windows与第三方使用条件未知，当前为内部候选。
