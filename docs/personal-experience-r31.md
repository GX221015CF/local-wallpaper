# R31 自用体验版

R31沿用既有CWP、视频、托盘与封面业务，补齐组件发现及持久个人库准备。默认使用者已自行合法安装联想壁纸。新程序、新个人库和旧观察库分别保存。

## 开始使用

从个人桌面快捷方式打开。首页自动复核保存的组件位置。未采用过组件时，只检查当前Windows的Program Files标准目录中固定的LxWallpaper安装位置，最多三个候选、总计30秒。自定义安装位置使用“选择组件目录”。

发现候选后会显示位置与兼容结果，点击“采用已核验组件”，阅读位置并确认。采用时重新核验23项完整文件身份，然后由正式机制保存。检查不会加载引擎或启动播放。后续每次启动和实际播放前仍复核；缺文件、身份改变及配置失效分别显示结果。

选中一张卡片 → 预览 → 画面正确时确认 → 关闭预览 → 设为桌面壁纸。个人库首次接入未复制旧播放确认。选中和正在使用分别显示。隐藏后从蓝色折框托盘图标找回，可以选择更换壁纸、停止播放并恢复原桌面或彻底退出。

## 个人资源

接入只针对明确列入本地清单的个人资源，通过实际身份和结构规则后，调用现有ManagedCatalog入库事务。每项最多256MiB、45秒。复制时校验原登记SHA-256、源文件稳定性及复制结果，封面经图片解码保存。相同哈希去重，失败保留原登记和接入记录，不改原库。其他官方缓存由用户通过既有导入窗口选择。

个人程序采用独立版本目录，绑定到独立持久个人数据位置。后续升级需验证新版本并沿正式部署机制保留绑定，禁止覆盖运行中的程序或重新创建空库。持久壁纸和封面继续占空间；仅新机制创建且正常停止已确认的运行副本按原R24规则回收。

## 桌面交互适配

参考用户组件库修订102的明确选用，采用WinForms自有控件适配。按压150ms、目标尺寸96%，点击波纹480ms、范围240%，等待转圈800ms；卡片悬停240ms、位移4逻辑像素。保留选中描边、运行标识、键盘焦点及行内真实错误。系统关闭客户区动画或使用高对比时，保留静态反馈和操作能力。未引入JavaScript、浏览器组件或其他运行依赖。

未为覆盖全部选用类别增加开关、拖拽、标签等新业务。组件与来源错误靠近对应操作；重复点击继续受原异步处理器和任务协调器保护。具体采用及未适用项见本地适配记录。

## 证据边界

R28本机视频与托盘、R29手动封面、R30导入前图片的真实反馈分别继承。R31自动发现、个人接入和交互适配的内部处理器/TEST_BUILD/发布Assembly准备与真实GUI体验分别记录。内部测试不能证明本版真实显示效果。

包内不含个人数据和第三方播放二进制。用户须合法准备匹配身份的组件及资源。第三方获取、配合使用及分发条件仍缺完整依据。其他Windows未实测，历史未登录结果只覆盖当时本机对应资源。
