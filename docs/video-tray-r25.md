# R25：视频缓存与托盘（内部验证）

使用完整解压目录里的 `build\LocalWallpaper.exe`。首次使用选择本软件数据位置；已保存库不会被默认空库替代。

点击“导入联想已下载壁纸”，在候选中选择已正常取得的资源，等待检查后明确导入。本版新增已识别的本地视频封装（固定异或传输的非碎片MP4、AVC视频，允许AAC音轨），不是仅凭MP4扩展名放行。读取范围仍为当前用户已知的联想缓存布局，不获取网络资源。

导入将原文件完整复制到所选数据位置的 `library`，视频保持`.mp4`和原始哈希；不改名为CWP，不解码另存整份视频。源记录与资源副本关联保存。R30在候选检查阶段自动离线截取视频画面，导入前显示识别图；导入后卡片复用同哈希图片缓存，手动截图继续可用。

选择卡片→点击“预览”→看见正确画面后点击“确认画面”。确认仅属于该资源哈希；导入本身不会确认或播放。桌面操作仍须先窗口确认。R28本机402242窗口与桌面画面已有用户正常反馈，声音和长时间循环未独立验收。

程序存活时有一个Windows通知区域托盘入口，可能在右下角“隐藏的图标”中。左键回到同一主界面；右键提供“打开主界面”“选择 / 更换壁纸”“停止播放并恢复原桌面”“彻底退出”。选择/更换只回到卡片，不自动播放。提示反映正在运行的条目，不把选中项当运行项。

“关闭界面，继续播放”仅在桌面运行时隐藏主界面，托盘保留；恢复与退出复用原停止清理链。托盘无法建立时不允许隐藏。彻底退出时停止并释放托盘。软件不修改系统托盘显示设置或开机启动。

组件由用户通过正式界面选择本机已有目录，并按固定23项身份重新核验。包不携带第三方播放二进制；运行时会暂存核验过的必要资源归档，加载仍来自已核验安装根。本版引擎视频类型参数来自同身份DLL静态调用链；内部验证不加载该DLL，真实兼容须用户明确操作。

未来运行副本正常停止并确认进程结束后回收，持久库不删。失败材料最多保留两份/128MiB，全部受管输入上限512MiB；活动、归属不明、重解析路径和清理失败保留并记录，最多三次删除尝试。日志和持久资源不属于此容量保证。R23及更早历史不扫描清理。

已通过的本机CWP真实观察继续有效；R28本机402242视频与托盘已获用户正常反馈，日志中的停止原因为controller-close，未单独证明tray-stop分支。其他电脑未实测，用户已取消其作为当前验收要求。第三方使用条件仍未核实，当前不是对外播放试用通过。
