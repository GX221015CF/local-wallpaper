# R37导入进度与持久检查缓存

版本为0.1.37-import-progress-internal-r37，当前用于内部自用体验。

## 导入进度

- 读取本地记录与检查缓存时总量尚未确定，显示蓝色不定进度及阶段说明。
- 检查队列确定后显示“已复用N项 · 本次检查X/Y次”。动态追加文件稳定性重试时，先更新分母，再等待和处理。计数采用实际完成的检查次数。
- 导入复制按处理器返回的实际字节显示进度。复制和完整哈希核验结束后，进入独立的保存登记阶段，登记成功后显示已入库。
- 取消时显示等待任务结束。完成、取消或失败后停止动画并收起轨道，保留结果文案。失败条数和结构未知条数保留在检查结果中。
- 减少动效时，不定进度采用静态蓝色片段，阶段文字继续更新。取消按钮、键盘入口和原生窗口行为沿现有流程使用。

## 持久缓存与重启

每个候选的检查结果保存到软件数据位置下的data/candidate-checks目录。复用会核对源路径和记录路径对应的缓存键、源文件签名、记录哈希、声明MD5、结果格式、规则指纹及封面有效性。

文件签名由长度、创建/写入/更改时间及卷和文件索引组成。复用条件没有开机时间、PID、进程会话或隔夜失效项。因此电脑重启本身没有让所有正常通过结果统一失效的代码条件。实际操作系统重启尚无验证记录。

重新打开时会读取小型记录、文件身份、规则及缩略图。资源或记录变化、规则变化、缓存缺失或损坏时，对相关目标重新检查。封面单独失效时，保留有效身份和结构结果，单独更新图片。临时IO/超时失败和部分封面结果的60秒及次数预算继续适用，关机期间的时间流逝可能让相关目标到期重试。主动重新检查针对所选目标执行。

## 验证范围

隔离进程A通过实际检查及保存入口生成小型自有资源结果并正常退出，进程B通过实际读取入口复用落盘结果。包含正常有效、保存两天、无封面、源/记录/规则变化、损坏或缺失缓存、封面失效及临时失败到期。有效结果在新进程中完整资源哈希为0字节，缩略图继续独立校验。源文件变化后的定向重查读取完整目标资源。

进度验证调用实际导入窗口处理器，包括扫描、全部命中、部分检查、追加队列、取消、复制、登记失败及再次开始。自有控件离屏绘制及模拟缩放用于核对几何与颜色。真实窗口视觉和连续使用体验由用户反馈确认。

R36筛选与名称成果继续作为基线。此前317495首次预览反馈及隔离登记保存偶发异常保留原始记录。其他Windows环境和第三方配合使用条件继续按现有证据范围管理。
