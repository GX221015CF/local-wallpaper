# R40界面与响应修订

## 本次五项

- 移除MaterialDialog整窗Bounds缩放动画。导入列表启用原生双缓冲，进度说明预留两行，文字及轨道更新合并布局，仅在实际高度变化时重新排版。R39完整集合提交与原生视口修正保持。
- 更多菜单处理可见关闭以及菜单自动关闭先于按钮Click的顺序。菜单外、Esc、命令和取消指针操作可正常再开，命令仍使用打开时资源。
- 重命名通过正式非模态入口显式按当前主窗体及所在工作区定位，打开前完成。设置等自有弹窗复用稳定定位，蓝色折框图标保持。
- 来源、持久库、名称缓存及组件位置使用只读路径行，完整路径可选中复制。来源继续使用原选择与校验，个人库及固定缓存保持原正式能力。文件夹不存在时给出说明并禁用打开操作。
- 首页右侧封面使用可取消后台解码及有界缓存，最多2解码、96项、8MiB像素数据。个人封面沿原20MiB/4000万像素显示预算，兼容BMP，导入图片原8MiB预算保持。资源身份、封面文件签名及选择代次关联迟到结果。相同选择不重复保存，无变化首次周期不重建卡片。选择保存仍同步完成后才更新界面，失败保留原选择。

## 内部证据与边界

自身控件OnShown及Application.Run对照捕捉到旧版约240ms内连续改变Bounds。首页正常选择入口分测保存、封面读取、身份状态和布局，另核对周期卡片重建。原始失败及前后结果保存在本地批次证据中。

测试覆盖连续选择、迟到图片、BMP、封面变化、重复选择、保存失败、关闭回收，菜单状态顺序、重命名保存/取消/Esc/重复定位，路径长文/不存在/窄窗及100/125/150字体布局。复用原生列表和导入响应回归。

未显示控件与离屏结果支持逻辑和几何结论。真实闪屏、物理菜单点击、实际缩放及切卡观感仍待一次合并体验。首页首批卡片的原有读取机制继续使用，切卡右图已独立后台处理。

## 一次体验

打开导入页观察检查和读条，关闭再开。回首页连续切换几张卡片，查看右图与名称，再开关更多、打开重命名并取消，查看设置路径排版。首次异常时停在当前状态，反馈大致时间。读取候选原45秒预算保持，10秒未出现首批候选可先反馈。本批体验仅涉及界面。

其他Windows、第三方使用条件及旧预览/保存缺口继续保持原范围。
