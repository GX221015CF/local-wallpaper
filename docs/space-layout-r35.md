# R35布局、菜单与确认配色

版本为0.1.35-space-layout-internal-r35，继续内部自用阶段。

## 使用变化

- 首页右侧按图片原比例、字体测量和实际可用高度排版，最多两行名称和简短说明，主要按钮保留正常字号及点击区域。
- 空间充足时封面扩展到当前宽度允许的比例高度，组间距有上限。内容表面达到舒适高度后停止拉长，避免末尾空白白板。短高度才压缩说明和重复封面。
- 底栏按标题、说明、播放名称和成功提示的字体实测高度分配两行，清除默认标签边距。长错误和长名称采用单行省略，完整错误保留在诊断及辅助说明中。
- 更多菜单保留WinForms原生开关、Esc、方向键和屏幕边界处理，通过自有Material Renderer统一表面、悬停、内边距和分隔。封面、详情、移除分组，移除仍需原确认且保留文件。
- 确认有效的卡片采用浅绿表面和确认文字。蓝色外框/勾选表示选中，独立正在使用标记表示播放。配色由既有可预览及当前身份确认规则计算，绘制过程不读资源或重算哈希。

## 验证边界

原R34底栏标题在当前字体需要26像素、实际只有15像素的红例保留在本地。右侧106逻辑像素封面上限导致增长无效的红例也保留。

定向验证包含实际未Show控件、GDI文字测量、100%/125%/150%模拟布局、常见工作区、长状态、菜单事件/Renderer及卡片状态组合。离屏组合图使用自有示意素材与实际绘制入口，不属于程序实拍。实际可见菜单的外部关闭、键盘焦点及整体观感由用户差异体验确认。

R34宿主提交恢复、R32截图和运行登记及自定义名称保存规则保持。317495首次预览尚无明确用户反馈，继续单独待确认，本批不安排重复播放。

其他Windows未实测，第三方配合使用条件仍未知，包不含第三方播放二进制。内部通过不扩展为对外试用资格。
