# R36导入体验修订

版本为0.1.36-import-refinement-internal-r36，当前用于内部自用体验。

## 界面与使用

右侧的封面、名称、按钮和状态按舒适内容高度组成一个整体，在主体区域垂直居中。短窗口采用既有紧凑布局。卡片显示“未验证 · ID …”或“已确认 · ID …”，现有确认颜色、选中和运行标记继续按各自状态显示。

导入列表保留名称/ID、大小、资源、检查和封面五列。“已入库”提示帮助识别重复资源。输入中文部分名称、ID或同ID的库内名称后，列表持续筛选并显示数量。清空查询恢复候选。扫描晚到、名称补全、检查完成和导入后都会应用当前查询。

已通过的目标可直接发起导入。程序先取消其余检查并等待当前任务正常结束，再通过原复制、完整身份复核和登记流程处理目标。导入期间暂时锁定查询与候选选择，防止操作对象发生混淆。

## 检查复用规则

- 检查缓存核对源文件身份、原记录、MD5声明和规则指纹。有效结果复用完整资源身份及结构结果，图片仍有独立的有效性校验。
- 已知缺少根目录静态预览图的结果，以及确定的结构失败或未知结构，保持到输入或规则变化、用户主动重查。
- 有效资源的临时封面失败按60秒间隔、同一身份最多3次单独重试。失效图片单独重建。完整资源检查结果继续保留。
- 具备完整身份条件的暂时IO检查失败按60秒间隔、同一身份最多3次自动检查。主动重查只针对所选资源。
- 视频重新生成图片需要转换私有媒体副本并核对该副本的源身份。该项哈希字节单独计量。
- 正式导入继续执行原复制与完整哈希校验。缓存命中及失效原因、资源哈希、缩略图校验、封面解码和视频转换分别计量。

## 本地官方名称

名称核对限定既有官方应用缓存中已认识的响应格式和路径。每批最多遍历1024条目录记录，最多读取16个允许响应，响应体上限2MiB，含一致性复核的响应读取预算8MiB，单批协作取消预算5秒。

索引仍要求既有标识、版本、131072桶及精确长度。累计目录预算按8MiB元数据约束，可覆盖32768条256字节记录。游标关联索引哈希、目标ID及缓存文件身份。下一批从上次位置继续，完整遍历后核对声明数量并处理同ID名称冲突。已完成查询复用结果，缓存变化后重新核对。

经核验的已有名称与用户自定义名称沿原保护规则保存。目标缺失、读取预算未完成、格式问题、变化及读取失败都有对应状态。缓存中的内容决定可补全范围。

## 验证

实际未Show控件入口覆盖TextChanged筛选、晚到候选、名称更新、别名、选择同步、隐藏队列取消及正式复制登记。自有4327条索引通过五批完成，并覆盖新进程读回、取消、冲突、链损坏和读取期间变化。

自有160字节有效无封面容器的对照实验表明，旧版再次检查读取160字节完整资源哈希，修正版复用结果时为0字节。该夹具用于确认缓存分支。实际界面观感与连续输入由用户差异体验确认。

R35隔离登记保存File.Replace偶发失败和317495首次预览反馈缺口继续保留。其他Windows环境及第三方配合使用条件仍待相应证据，当前按内部版本管理。
