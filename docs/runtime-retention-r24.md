# 运行副本空间管理（R24内部候选）

导入库中的壁纸、封面和确认属于持久资料，不参与清理。新机制只登记数据目录runtime-inputs-r24内、由本版创建的未来运行input.cwp。旧R23及更早运行材料完全不纳入。

正常停止：worker记录宿主已结束，控制端用已持有句柄确认worker/宿主结束后维护；回收大型输入，保留请求、原始事件、结果、资源哈希和清理摘要。下次准备也尝试恢复维护。

失败：保留原始错误和日志；最新两份已结束的失败输入合计最多128 MiB，超限仅回收已核实结束/归属的原件，摘要不丢。单份超过128 MiB的失败原件也不永久保留。所有运行输入（含活动、部分复制和待清理预约）合计最多512 MiB、最多64项；不能安全回收则拒绝新准备，已导入资料保持。

安全：运行中、未知、身份不符、未知文件、重解析点拒删；仅按完整拥有记录及精确进程创建身份判断，不按文件时间推定。每次维护最多500毫秒（停止回调150毫秒）的合作预算，64项上限；文件系统调用本身不能强制中断。每份删除最多3次，失败保持及计入预算。关闭不等待无限清理，后续准备可恢复已结束记录。达到重试上限需诊断，程序不会暗中放开容量。

管理范围只限制大型运行输入，日志及用户导入库仍可能增长，不能声称整个数据目录永不增长。未知异常退出未写可信结束记录的材料安全保留，可能最终阻止新准备；不通过猜测清理。

本包不带用户绑定、数据、CWP/封面、第三方播放组件或历史诊断。真实播放沿R23有效结果复用，但R24新资源路径仍待一次手动预览、正常停止的差异观察；没有外部试用或其他电脑兼容结论。
