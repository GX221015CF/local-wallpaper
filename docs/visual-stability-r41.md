# R41视觉稳定修订

## 已查清的切卡抽动

通过实际SelectWallpaper与后台图片提交入口，横图、竖图、方图及无图夹具复现到清空/到图后的面板高度和居中位置变化。原布局按当前图片实时比例计算视口，空图使用16:9；名称按当前行数计算。之前同一比例的性能夹具没有覆盖这个变化。

本版图片视口按可用窗口宽高确定，名称、说明及运行文字预留两行，小高度再按窗口约束紧凑。图片使用Zoom完整等比适配，允许留白。切卡加载显示中性占位及状态，沿用后台解码、有界缓存、文件身份与迟到结果检查。窗口尺寸和真实确认操作行变化仍可触发布局。

## 重命名

标签放在编辑框上方。单行输入按真实字体测量分配高度，上下留白，焦点描边。80字符、中文选择和光标、校验、保存失败保留内容、Enter、取消/Esc、图标及工作区居中保持原业务链。

## 设置标签

采用自有WinForms统一标签栏及页面容器，替代原生TabControl外框与胶囊叠加。四组内容保留，点击后立即切页，蓝色下划线约240ms移动，快速切换从当前插值更新目标。减少动效立即到位。保留箭头/Home/End、CtrlTab、可见焦点、可访问名称与选中状态，隐藏/重开/缩放重置当前目标，退出释放计时器。没有新增运行依赖。

## 验证范围

自有横竖方无图、冷/缓存、异步清空到图及长名称，在默认/较小窗口记录面板、图片、标题和主要按钮矩形。100/125/150使用字体与几何模拟，补充迟到快切、状态文字、重命名失败与输入、标签动画重定向/键盘/减少动效/隐藏重开/关闭回收及离屏图。

内部几何、事件、消息循环和离屏结果分别保存，真实视觉仍需用户一次体验。R39列表与R40图片、菜单、保存失败结果按受影响链回归，旧预览、隔离保存和其他Windows边界保持。

## 一次最短体验

从桌面本地壁纸打开，连续选几张不同比例的已有卡片，查看右侧是否稳定。打开重命名检查输入空间并取消。切换四个设置页观察内容与下划线，再正常退出。首个异常时停在当前状态反馈。
