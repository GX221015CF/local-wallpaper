# 视频截取封面

完整解压后打开 `build\LocalWallpaper.exe`。在首页选中已导入的视频，点击“预览”。

1. 等到喜欢的画面，在预览窗口点击“截取封面”。保持预览完整可见，等待最多10秒。
2. 出现“封面已保存，首页卡片已更新”后，可继续播放，也可点击“关闭预览”查看卡片。
3. 想换一帧时点击“替换封面”，在确认框中选择“是”。选择“否”会保留已有封面。
4. 正常退出并重新打开，已保存的截图继续作为该资源的卡片封面。

主界面的“用当前画面作封面”入口也可使用。截图只读取本软件当前窗口预览的渲染区域。窗口最小化、被遮挡或未取得有效画面时会提示失败，黑图和失败不会覆盖旧封面。深色或细节极少的画面也可能因空白检查而被拒绝，可选择另一帧。

图片按完整资源SHA-256保存到当前软件数据位置的 `data\preview-covers`，最大480×300像素，每张不超过2MiB。同一资源的登记可以复用封面，其他内容不会借用这张图。已有独立封面受保护；自动视频帧允许后续手动截图替换显示。截图与人工播放确认分别保存。

正常结束回收的是运行壁纸副本，截图封面和必要日志继续保留。替换前的历史截图文件可能保留，此功能未加入图片历史空间清理。

R28已有本机402242窗口、桌面及托盘用户反馈，停止退出与运行副本回收有日志证据。R29继承视频接线，本轮新增截图路径及按钮，R29真实截图已获用户正常反馈并核对两张不同画面；R30保留此功能。其他电脑未实测，第三方使用条件未核实，按内部候选管理。
