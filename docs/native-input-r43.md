# R43原生鼠标移动接入

## 已定位的自有遗漏

已核对的官方播放器通过引擎公开slot0x3c传入渲染窗口、消息、按钮及打包坐标。引擎将消息排队，在自己的线程转换为场景鼠标事件，最终写入粒子控制点输入位置。原自有宿主缺少此接入。

墨染ID385726控制点0的flags=1进入外部位置向量分支。粒子系统初始该向量为远离画面的占位坐标，鼠标事件更新后再经引擎自身坐标变换使用。此前粒子和着色器加载完成不能证明控制点已收到输入。

## 实际接入

沿用完整CWP、默认工厂、原组件身份和原播放初始化。CWP成功启动后，仅向已核验的自有渲染窗口提交WM_MOUSEMOVE，坐标为该窗口客户区像素。预览真实鼠标移动与33毫秒有界读取共用入口，相同位置去重并限制提交频率，最新位置由下一次读取更新。桌面层后的宿主通过只读鼠标位置取得移动，不安装钩子、不转发点击或键盘、不捕获或移动鼠标，不改变焦点或图标处理。

越出当前渲染客户区或超过消息坐标范围时忽略输入。停止前关闭输入计时器，结束后回调被拒绝，释放图形引擎与日志保持独立清理。输入失败仅关闭输入接入并保留首个错误，原停止退出机制继续工作。纯视频路径保持输入关闭。

## 证据边界

实际未显示DesktopHost.Start与Surface.MouseMove经ABI替身复现零输入，修正后定向验证覆盖参数、时序、像素映射、快速移动、异常和释放。替身没有加载第三方引擎，真实光点出现及桌面观感待用户手动观察。

scenegroup配置错误与slot0x60额外选项保留独立调查结论。当前接入保持它们原有处理，原资源、isVip、vipeffect、vipfuncgroup及第三方授权校验保持。设置底色、稳定视口、名称编辑、截图与登记原子保存成果继续使用。
