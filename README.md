# 本地壁纸 · R42设置底色修订

这是Windows本地动态壁纸工具的内部阶段源码。R31基于R30推进组件有界自动发现、独立持久个人库及WinForms交互适配。使用者默认已自行合法安装联想壁纸。详见 [自用体验说明](docs/personal-experience-r31.md)。

正常使用路径为选择软件数据位置 → 发现已正常取得的本地缓存 → 自动检查并显示封面或视频画面 → 明确导入 → 选中卡片 → 预览并人工确认 → 应用桌面 → 停止恢复或隐藏后从托盘找回 → 正常退出。

R32集中修正预览截图的有限取帧、诊断阶段和运行登记原子替换竞争。原R31个人部署与既有真实结果保持分项记录，详见 [稳定性修订](docs/stability-r32.md)。

R33将首页技术信息归并到固定设置入口，并增加持久重命名与Material桌面交互适配。[本版说明](docs/material-settings-rename-r33.md)区分内部验证和真实体验。

R34修正宿主目录提交的有条件恢复、故障材料表达、非模态取消、分组选中和右侧免滚动。[本版说明](docs/refinement-r34.md)保留原始错误与内部/真实观察边界。

R35按真实字体分配底栏高度，按可用空间分配右侧封面与组间距，统一Material菜单，并按有效预览确认显示浅绿卡片。[本版说明](docs/space-layout-r35.md)区分离屏检查与真实观感。

R36将右侧操作主体垂直居中，卡片使用短状态，导入列表提供持续筛选、检查结果复用及有进度的本地名称核对。[本版说明](docs/import-refinement-r36.md)记录预算和验证范围。

R37采用蓝色Material进度，读取、队列计数、复制字节和登记按实际任务更新，结束后收起轨道。检查缓存已用两个独立进程验证保存、复用及失效条件。[本版说明](docs/import-progress-r37.md)记录重启语义与验证范围。

R38把导入结果解析与图片解码移到后台，分批呈现候选文字并逐步填充图片，复用图片并减少重复列表、详情及进度更新。[本版说明](docs/import-response-r38.md)区分消息循环测量与真实手感。

R39修正筛选缩减时的原生负顶部索引和行位置异常。可见集合变化时按原模型顺序提交行，在提交结束后恢复选择和合理视口，图片后台与缓存继续复用。[本版说明](docs/import-list-r39.md)记录点击前的原生矩形与离屏绘制检查。

R40取消弹窗整窗尺寸动画，稳定导入进度布局，增加更多开关状态、非模态定位与设置路径行。首页选中封面采用有界后台解码与身份复用，避免无变化首次周期重建。[本版说明](docs/interaction-r40.md)区分内部响应、控件绘制和真实观感。

R41将右侧视口与文字行预算从图片比例、名称长度中独立出来，重命名采用上方标签及独立编辑区，设置使用立即切页和240ms滑动下划线。[本版说明](docs/visual-stability-r41.md)记录几何红绿及验证范围。

R42设置四标签采用220ms选中底色过渡，内容立即切换。墨染ID 385726原生粒子已完成有界静态证据复核，启用与输入的直接缺口仍待收敛。[本版说明](docs/settings-color-r42.md)区分已交付界面与粒子调查。

## 已完成的阶段能力

- 已支持布局中的CWP-v2、已认识的CWP-v3结构族及LX本地AVC视频封装，采用完整身份与路径检查。
- 多壁纸卡片、选中项与运行项区分、预览确认按资源隔离、正常停止和退出清理。
- 系统托盘、隐藏后找回、停止恢复和彻底退出，蓝色折框图标。
- 导入前自动离线取得视频画面，导入后卡片复用图片。保留预览窗口手动截取或替换封面。
- 自有新运行副本正常停止后回收，故障材料有保留预算。持久壁纸、图片和日志单独保存。

R28视频/托盘、R29手动封面、R30导入前图片分别具有本机真实反馈。各版本观察范围见 [阶段报告](docs/stage-report.md) 和 [证据摘要](docs/verification-summary.json)。R31的构建与定向验证另行记录，原R30副本及其有效证据保持原位。

## 从源码构建

本机需已安装Windows、PowerShell 7，以及 `%WINDIR%\Microsoft.NET\Framework\v4.0.30319\csc.exe` 和同目录.NET Framework引用程序集。自有程序编译为x86。

```powershell
pwsh -NoProfile -File .\scripts\Build-Delivery.ps1
```

每次在 `artifacts/build-时间/source` 创建独立构建阶段，输出自有EXE、规则、完整内部ZIP及输入/工具/输出回执。宿主构建会生成新的身份哈希，只在该阶段副本内更新，维护源码和旧产物保持可核对。底层 `build-support` 脚本由入口复制到阶段后执行。

独立无界面源码检查使用本机已有Python 3和.NET编译器。

```powershell
python -B .\scripts\Test-SourceDelivery.py
```

测试自行生成小型合成CWP夹具，只用于结构和登记处理器。真实视频/壁纸样本及第三方组件不在仓库中；历史大样本测试代码保留，运行材料由调用者另外明确准备。测试不会证明真实渲染效果。

## 文件结构

- `src/`、`host_src/`、`shared/` 为应用、宿主和共享自有代码。
- `rules/` 为已支持结构与固定组件身份规则，`assets/` 为选定图标。
- `tests/` 为测试源码，`scripts/` 为独立构建与检查入口，`build-support/` 为阶段内底层构建脚本。
- `docs/` 为使用、范围、阶段和经过脱敏的证据摘要。`SOURCE_ORIGIN.json` 记录原R30文件身份。
- `artifacts/` 和 `tests/isolation/` 仅本地生成，Git排除。

任务当前状态在外层工作区唯一的 `work/ACTIVE_TASK.md` 中维护。此仓库保存源码阶段，不另建任务状态。

## 运行依赖与支持范围

自动视频封面使用Windows系统Media Foundation能力。播放依赖用户已合法取得、且身份符合固定23项契约的本地播放组件，可有界发现，首次须通过界面明确采用并重新核验。内部包只包含自有宿主和程序。DLL从选定安装根加载，必要资源归档按实际运行机制暂存。组件获取与配合使用条件仍待可靠核实。

本机401999、317495、395741的CWP结果以及402242的视频结果见分项证据。398417、403178目前具有取帧证据，未因此宣布真实播放通过。其他Windows未实测，用户已接受其作为技术限制保留。

未登录条件下395741的新缓存导入与窗口使用只覆盖本机该资源，机器级权益历史尚未排除。它不构成全部资源的免费、长期使用或再分发结论。

本仓库未指定开源许可。第三方程序、壁纸资源和其他内容的权利及使用条件需分别确认。当前按私有内部阶段项目管理。
