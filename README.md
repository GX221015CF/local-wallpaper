# 本地壁纸 · R43原生鼠标输入修订

这是Windows本地动态壁纸工具的公开源码项目，程序当前仍为内部阶段版本 `0.1.43-native-input-internal-r43`。维护源码由R30基线持续开发至R43，支持本地资源导入、窗口预览、桌面播放及个人库管理。播放组件和壁纸由使用者自行合法准备。

这是独立开发的兼容工具，适合已合法取得相应资源和已核验播放组件、愿意自行构建并了解验证范围的Windows使用者。项目由个人维护，非联想官方出品，官方产品名称用于说明兼容目标。维护者有权授权的自有内容采用MIT许可，版权署名为2026 GX221015CF。[完整许可证](LICENSE)

正常使用路径为选择软件数据位置 → 发现已正常取得的本地缓存 → 自动检查并显示封面或视频画面 → 明确导入 → 选中卡片 → 预览并人工确认 → 应用桌面 → 停止恢复或隐藏后从托盘找回 → 正常退出。

## 当前成果

- 导入窗口支持中文名称、ID及别名持续筛选，候选文字分批呈现，图片后台加载。检查结果持久保存，跨进程按文件、记录、规则和封面身份复用。读取、检查、复制与正式登记分别反馈真实进度。
- 首页区分选中、正在使用与有效预览确认，确认卡片采用浅绿底色。右侧使用稳定的等比图片视口，切卡图片在后台读取。名称可持久修改，设置提供四组功能和选中底色过渡。
- 支持已认识的CWP-v2、CWP-v3结构族及LX本地AVC视频封装，导入采用身份与结构检查。视频封面可由系统离线取帧，预览保留手动截取和替换封面。
- 保留系统托盘、隐藏后找回、停止恢复、彻底退出，以及正常结束后的受管运行副本回收和故障材料保留预算。
- R43补齐原生鼠标移动输入。“墨染”ID385726的粒子已获用户确认，与官方渠道效果一致。该反馈未逐模式指定观感，预览和桌面的输入与正常退出分别有运行日志支持。[R43说明](docs/native-input-r43.md)

## 使用流程与运行依赖

首次使用通过正式流程选择软件数据位置，并明确采用本机已有的播放组件。程序会有界发现和逐项核验固定23项外部组件身份，包内提供自有程序、宿主与规则。DLL从用户选择的安装根加载，必要资源归档沿运行机制暂存。个人库、来源、组件配置、名称和确认独立持久保存，升级通过正式版本机制继续关联原库。

自动视频封面依赖Windows系统Media Foundation能力。本机已验证的第三方安装身份有固定契约，其他组件版本的兼容性需另行核验。其他Windows环境尚未实测，该项已取消为当前备份与阶段交付的前置条件。

## 构建与本机工具

使用本机已有Windows、PowerShell 7、`%WINDIR%\Microsoft.NET\Framework\v4.0.30319\csc.exe` 和同目录.NET Framework引用程序集。自有程序编译为x86。

```powershell
pwsh -NoProfile -File .\scripts\Build-Delivery.ps1
```

每次在 `artifacts/build-时间/source` 创建独立构建阶段，输出自有EXE、规则、完整内部ZIP及输入/工具/输出回执。宿主构建会生成新的身份哈希，只在该阶段副本内更新，维护源码和旧产物保持可核对。底层 `build-support` 脚本由入口复制到阶段后执行。

独立无界面源码检查使用本机已有Python 3和.NET编译器。

```powershell
python -B .\scripts\Test-SourceDelivery.py
```

测试自行生成小型合成CWP夹具，只用于结构和登记处理器。真实视频/壁纸样本及第三方组件不在仓库中；历史大样本测试代码保留，运行材料由调用者另外明确准备。测试不会证明真实渲染效果。

R43有效程序已于2026-11-12完成正式构建、包校验、同库部署及发布处理器检查。此次说明整理沿用该功能版本和二进制，更新后的仓库文档属于后续文档提交。

## 验证范围与历史

R43有27项原生输入、52项视频初始化ABI、13项关闭、36项视觉、19项设置底色、13项稳定性及1项独立进程回读检查，共161项自有验证，另有10项静态路由检查。消息循环、几何、离屏绘制、发布程序集及ABI替身的结果分别记录。R43真实粒子结果来自用户画面反馈，日志支持两个模式的输入和正常释放。

R28视频与托盘、R29手动封面、R30导入前取帧分别沿用当时的本机真实证据。398417、403178具有取帧证据，播放验证范围依旧单列。R33首次宿主提交失败、317495首次预览观察缺口和隔离登记保存的早期异常保留。R41其他视觉与R42底色观感按各自反馈记录。

阶段沿革和边界集中在[阶段报告](docs/stage-report.md)、[验证摘要](docs/verification-summary.json)与[说明索引](docs/README.md)。R30原始提取身份及独立构建快照分别保存在 `SOURCE_ORIGIN.json` 与 `docs/source-validation-summary.json`，两者属于历史基线。

## 文件结构

- `src/`、`host_src/`、`shared/` 为应用、宿主和共享自有代码。
- `rules/` 为已支持结构与固定组件身份规则，`assets/` 为选定图标。
- `tests/` 为测试源码，`scripts/` 为独立构建与检查入口，`build-support/` 为阶段内底层构建脚本。
- `docs/` 为使用、范围、阶段和经过脱敏的证据摘要。`SOURCE_ORIGIN.json` 记录原R30文件身份。
- `artifacts/` 和 `tests/isolation/` 仅本地生成，Git排除。

任务当前状态在外层工作区唯一的 `work/ACTIVE_TASK.md` 中维护。此仓库保存源码阶段，不另建任务状态。
